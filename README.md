
# InternGrow Backend Development

A complete backend development internship project built using Node.js, Express.js, PostgreSQL, REST APIs, authentication, security, performance optimization, and monitoring.

## 📚 Weekly Projects

- Password Hashing
- JWT Authentication
- Protected Routes
- Role-Based Authorization

### Week 2 — HR Management API
- Employee Management
- HR-related REST APIs
- CRUD Operations
- PostgreSQL Database

### Week 3 — E-Commerce Backend
- Product Management
- Category Management
- CRUD Operations
- REST APIs
- PostgreSQL

### Week 4 — Project Management System

- Task Management
- Task Assignment
- Comments

### Week 5 — API Optimization & Security
