# Week 4 — Project Management System

A backend Project Management System developed using Node.js, Express.js, and PostgreSQL as part of the InternGrow Backend Development Internship.

## 🚀 Features

- Team Management
- Project Management
- Task Management
- Task Assignment
- Comments
- Activity Logs
- Notifications
- File Attachments
- RESTful APIs
- PostgreSQL Database

## 🛠️ Technologies Used

- Node.js
- Express.js
- PostgreSQL
- JavaScript
- REST API
- Postman
